# 截图目录

这里放界面截图，供根目录 `README.md` 引用。建议尺寸 1280×800 或 1440×900（PNG，单张 < 300 KB）。

命名约定：

| 文件 | 内容 |
|---|---|
| `panel-dashboard.png` | 仪表盘：运行状态、指令执行数、最近语音 |
| `panel-rules.png` | 意图规则：规则列表 + 编辑展开状态 |
| `panel-xiaomi.png` | 小米账号：扫码登录区域 |
| `panel-devices.png` | 设备管理：别名与设备列表 |

补图步骤：

1. 在真实 HAOS 里打开侧边栏面板，截取对应页面（**注意先遮掉小米账号、HA Token、实体名等隐私信息**）；
2. 按上表命名后放进本目录；
3. 在根目录 `README.md` 的「界面预览」小节把占位说明替换成：

   ```markdown
   | 仪表盘 | 意图规则 |
   |---|---|
   | ![仪表盘](docs/images/panel-dashboard.png) | ![意图规则](docs/images/panel-rules.png) |
   ```

4. 删掉「界面截图待补充」那行占位。
