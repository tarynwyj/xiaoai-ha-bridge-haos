# 安装与首次配置

装完之后，你应该能在 Home Assistant 侧边栏打开面板、用小米账号登录、连上自己的
Home Assistant，并对音箱说一句话让某个设备动起来。

## 开始之前

| 需要 | 说明 |
|---|---|
| Home Assistant OS | 本项是加载项，需要 Supervisor；Home Assistant Container 装不了 |
| amd64 | 目前只有 amd64 镜像，ARM 设备（比如树莓派）用不了 |
| 小米账号 | 账号下至少有一台小爱音箱、触屏音箱或智能屏 |
| Home Assistant 长期访问令牌 | 等下要填进面板 |

小米账号里那台音箱要能正常用米家 App 控制、能和小爱对话。音箱本身不用做任何改造。

## 1. 添加加载项仓库

Home Assistant → 设置 → 加载项 → 右上角 ⋮ → **仓库** → 粘贴

```
https://github.com/tarynwyj/xiaoai-ha-bridge-haos
```

点「添加」，然后关掉对话框，回到加载项商店。

## 2. 安装并启动

在加载项商店里找到 **XiaoAI HA Bridge**，点进去选「安装」。下载完成后点「启动」，
等状态变成「已启动」。

这一步只装加载项，还没有连小米，也没有连你的 Home Assistant。

## 3. 打开面板

左侧边栏会出现 **小爱语音桥接**。点开就是管理面板。

- 面板走 HAOS Ingress，用的是 Home Assistant 自己的登录，只有管理员能打开；
- 如果侧边栏没有这一项：设置 → 加载项 → XiaoAI HA Bridge → 打开「显示在侧边栏」；
- 也支持直连端口，见文末。

## 4. 登录小米账号

打开「小米账号」页，点「扫码登录」，用米家 App 扫屏幕上的二维码，手机上确认。

扫码是最省事的方式。如果手机上不方便操作，还有账号密码 + 验证码、手动 Cookie 等几种方式，
步骤和注意事项见 [登录小米账号](login.md)。

登录成功后，同一页的「接收语音的小爱音箱」会列出账号下的音箱。默认监听全部，
只有一台的话不用改。

## 5. 连接 Home Assistant

打开「Home Assistant」页：

1. 填地址。加载项和 Home Assistant 在同一台机器上，常用
   `http://homeassistant.local:8123`；如果你的 HA 换了端口或地址，填实际能访问的那个。
2. 填长期访问令牌。在 Home Assistant 里点左下角头像 → 个人资料 → 拉到最下面
   「长期访问令牌」→ 创建令牌 → 复制。
3. 点「测试」。提示连接成功即可。

令牌只保存在本加载项的 `/data` 里，用来调用 Home Assistant 的服务。

## 6. 加第一条规则

打开「意图规则」页，点「新增」：

| 字段 | 填什么 |
|---|---|
| 规则名称 | 随便起，只给人看；不填就用触发语句当标题 |
| 触发语句 | 你要说的那句话，例如 `打开客厅灯` |
| 设备类型 | 灯光 |
| 操作 | 开 |
| 目标设备 | 在复选框里勾上客厅那盏灯 |
| 回复 | 可选，例如 `好的`，执行完小爱会念出来 |

点这条规则右侧的「保存」，然后回「仪表盘」点「启动」。

## 确认装好了

对音箱说「打开客厅灯」，然后看仪表盘：

- 「最近」出现你刚说的那句话；
- 「指令执行」的数字加一；
- 灯亮了。

三样都对，说明整条链路通了。如果哪一步不对，按 [故障排查](troubleshooting.md) 里的
「说了话没反应」往下查。

## 备用入口：直连端口

面板打不开时，还可以直接访问 `http://<Home Assistant 主机IP>:47521`。
从 1.0.10 起这个入口需要直连令牌：

- 在面板「高级设置 → 显示直连令牌」查看；
- 直连是明文 HTTP，只在可信局域网用，不要暴露到公网；
- 日常使用建议还是走侧边栏面板。

令牌文件在容器内 `/data/config/.access_token`，删掉它并重启加载项会重新生成一个。
