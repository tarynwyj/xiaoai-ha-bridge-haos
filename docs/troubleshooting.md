# 故障排查

先看「实时日志」，大部分问题在那里有明确原因。下面是按症状查的清单。

## 侧边栏没有面板

1. 加载项是否在运行：设置 → 加载项 → XiaoAI HA Bridge，状态应为「已启动」；
2. 是否打开了侧边栏显示：同一页里打开「显示在侧边栏」；
3. 当前账号是不是 Home Assistant 管理员——面板只对管理员可见；
4. 还是不行，用直连端口 `http://<主机IP>:47521` 应急，令牌在「高级设置 → 显示直连令牌」。

## 面板空白、一直转圈

看实时日志里有没有这句：「收到 Ingress 请求但来源 … 不是 Supervisor」。

有，说明请求没走 Supervisor 代理（常见于自建反向代理、端口映射），改用侧边栏入口。
没有，刷新页面；升级后浏览器停在旧页面会自动跳一次登录，属正常。

## 说了话，但什么都没发生

先看仪表盘的「最近」有没有你刚说的那句话。

**没有新语音**：桥接器没听到。看面板顶部的提示：

| 提示 | 含义 | 怎么办 |
|---|---|---|
| 正在自动重试 | 网络或小米服务抖动 | 等一会儿，会自己恢复 |
| 登录凭据已失效（code=…） | 小米拒绝了这份凭据 | 重新登录，见 [登录小米账号](login.md) |
| 没有任何提示 | 桥接器可能没在轮询 | 仪表盘停止再启动一次 |

如果你限定了监听范围，还要确认当前说话的这台在范围内。

**有语音，但设备没动**：规则没匹配上，或者实体 ID 不对。到规则页测试区输入同一句话，
看命中哪条规则、准备执行什么；没命中就调整触发语句，命中了但执行失败就看 Home Assistant
自己的日志。

**「指令执行」加了，设备还是没动**：问题在 Home Assistant 那边，检查实体当前状态、
服务权限，或者这个设备是不是被别的自动化覆盖了。

## 连不上 Home Assistant

「Home Assistant」页点「测试」失败，按顺序看：

1. **地址**：加载项跑在容器里，写 `http://localhost:8123` 指的是容器自己，连不到你的 HA。
   用 `http://homeassistant.local:8123` 或宿主机的局域网 IP（例如 `http://192.168.1.10:8123`）；
2. **端口**：HA 默认 8123，改过就填实际端口；
3. **令牌**：长期访问令牌被撤销或复制不全都会导致失败。回 HA 个人资料页重新创建一个，
   粘贴时注意不要带多余空格；
4. **协议**：HA 用 https 时，证书要能被加载项信任，自签证书可能连不上；能走内网 http 就用 http。

改完点「测试」会当场给出结果，不用重启桥接器。

## 定时任务不对

| 现象 | 原因与处理 |
|---|---|
| 看不到刚建的任务 | 列表会标「HA 未加载」，回读成功才算建好，等几秒刷新 |
| 一次性任务没执行 | 标了「已过期未执行」，说明到点时 HA 没在运行；改时间重排 |
| 时间对不上 | 一切以 Home Assistant 配置的时区为准，检查 HA 的时区设置 |
| 语音说的任务没建成 | 日志会写缺什么，通常是设备名和 HA 里的名字对不上，先起别名再说一遍 |

## 登录相关问题

| 提示 | 处理 |
|---|---|
| 验证会话已失效 | 验证码会话 5 分钟过期，点「重新开始」重新登录一次 |
| 验证码不正确（还可尝试 N 次） | 输错会累计，连错 5 次要重新登录 |
| 缺少 serviceToken / passToken | 小米没返回可用凭据，不会写入任何文件，旧登录保留，重试或换方式 |
| 设备列表获取失败 | 凭据没通过校验，同样不写盘；检查网络后重试 |
| code=70016 | 这张 Cookie 票失效了，先在浏览器重新登录取新票，见 [登录小米账号](login.md#提示-code70016) |

## 直连端口打不开或一直要登录

- 从 1.0.10 起直连端口需要令牌，「高级设置 → 显示直连令牌」里查看；
- 加载项重启后，浏览器里的直连会话会失效，重新输入令牌即可；
- 点过「退出登录」之后，旧 Cookie 不能再用，这是设计如此。

## 数据文件出问题

- 日志提示去重文件损坏：桥接器会停止而不是乱执行，检查文件或从备份恢复，不要直接删；
- 日志提示凭据文件身份不一致：说明两个凭据文件不同步，重新登录一次即可；
- 磁盘满或 `/data` 只读：令牌、配置可能写不进去，先释放空间或修复权限。

## 反馈问题时附上

加载项版本、Home Assistant 版本、复现步骤、日志片段。**发之前删掉 Cookie、令牌和账号信息。**
