# 升级与回退

## 升级

在 Home Assistant 的加载项商店里，XiaoAI HA Bridge 有新版本时会显示「更新」。
点更新，等加载项重启完成。

升级不会删除 `/data`，规则、别名、登录凭据都保留。升级后如果浏览器还停在旧页面，
会提示会话失效并自动刷新，属正常现象。

升级前建议做两件事：

1. 规则页导出一次 JSON（多一层保险）；
2. 设置 → 系统 → 备份，做一次完整备份。

## 升级后逐项确认

| 检查项 | 怎么确认 |
|---|---|
| 侧边栏面板 | 能打开，能看到状态、规则、设备 |
| 直连端口 | 打开 `http://<主机IP>:47521` 有登录页，粘令牌能进 |
| 规则还在 | 规则页能看到原来的规则，多选设备没丢 |
| 语音链路 | 说一句已有规则，设备动作，仪表盘计数加一 |
| 定时任务 | 定时任务页还能看到 `xiaoai_bridge_*` 自动化 |

## 回退

加载项商店不列历史版本，所以回退只有这几条路：

**首选：从备份还原。** 设置 → 系统 → 备份 → 选升级前那份 → 部分还原 → 只勾选
XiaoAI HA Bridge（含数据）。还原后加载项回到旧版本，镜像标签还在，能正常拉取。
代价是 `/data` 会回到备份那一刻，这期间产生的去重时间戳等会丢。

**只想回退代码、保留当前数据。** 手工拉旧镜像再让商店指向它（高级操作，不推荐），
或者把本地仓库 `config.yaml` 里的版本号改回旧版本再安装。

**回退后**：如果提示重新登录，就重新登录一次；然后说一句话确认链路正常。

## 版本与兼容

- 版本号在 `xiaoai_bridge/config.yaml`，镜像按版本号发布，`ghcr.io/tarynwyj/xiaoai-ha-bridge-haos:<版本>`；
- 各版本改了什么见 [CHANGELOG](../xiaoai_bridge/CHANGELOG.md)；
- `/data` 结构在 1.0.9 到 1.0.10 之间做过升级、回退验证；1.0.11、1.0.12 只改登录流程，
  凭据文件结构未变。更早或更晚的跨版本组合没有逐一验证，回退时优先用备份还原。

## 面板打不开时

直连令牌在 `/data/config/.access_token`，可以用 SSH 或文件管理加载项读出来。
日志里只提示文件位置，不打印令牌本身。
