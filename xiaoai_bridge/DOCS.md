# 使用说明

小爱音箱语音桥接：把小爱听到的话变成 Home Assistant 里的动作。

这份说明在加载项页面的「文档」页里显示。更细的分主题文档在 GitHub：
[文档目录](https://github.com/tarynwyj/xiaoai-ha-bridge-haos/blob/main/docs/README.md)。

## 打开面板

**推荐**：Home Assistant 左侧边栏 →「小爱语音桥接」。它走 HAOS Ingress，沿用 Home Assistant
登录，只有管理员能打开。

**备用**：直连端口 `http://<主机IP>:47521`，从 1.0.10 起需要直连令牌，在面板
「高级设置 → 显示直连令牌」查看。直连是明文 HTTP，只在可信局域网用。

## 配置三步

1. **小米账号**：扫码登录（推荐）；也可以账号密码 + 验证码，或手动填 Cookie。
2. **Home Assistant**：填地址（例如 `http://homeassistant.local:8123`）和长期访问令牌
   （HA 左下角头像 → 个人资料 → 长期访问令牌），点「测试」，连接成功后点「保存」
   （只测试不会保存）。
3. **意图规则**：新增规则，填触发语句、选设备类型与操作、勾选目标设备，点这条的「保存」，
   然后回仪表盘点「启动」。

## 意图规则要点

一条规则 = 触发语句 + 一个动作 + 一组设备。

| 字段 | 说明 |
|---|---|
| 规则名称 | 只给人看，不参与匹配 |
| 触发语句 | 你要说的话；`{num}` 表示一个数字 |
| 设备类型 | 灯光 / 开关 / 空调 / 场景 / 媒体 / 脚本 / 自动化 / 虚拟开关 |
| 操作 | 按类型给出，例如开、关、调温、执行 |
| 目标设备 | 复选框，可多选，支持搜索与全选 |
| 回复 | 执行完小爱念的话，可留空 |

- 规则从上到下匹配，第一条命中就停；
- 带数字：语句写 `把空调调到{num}度`，温度填 `{0}`；
- 每条规则单独「保存」，顶部「保存全部」才一起提交；
- 规则页顶部测试区可以先输入一句话看匹配结果；
- 支持导出 / 导入 JSON。

## 定时任务

两种建法，效果一样：对小爱说「明天八点打开热水器」「每周一三五晚上九点关灯」
「十分钟后关灯」，或在定时任务页用表单建（选设备、操作、时间、重复方式）。

- 建出来的是 Home Assistant 里的自动化，名字以 `xiaoai_bridge_` 开头，桥接器没在跑也会执行；
- 同一句话重复说不会建多条；
- 列表可编辑、暂停 / 启用、清理已完成；
- 一次性任务执行后标「已完成」；到点时 HA 没运行会标「已过期未执行」；
- 时间一律以 Home Assistant 的时区为准。

## 多台小爱音箱

默认监听账号下所有小爱设备，对哪台说话都算数，回复念在刚说话那台。

要限定范围：小米账号页 →「接收语音的小爱音箱」→「仅监听所选音箱」→ 勾选 → 保存 → 重启桥接器。
「全部」模式下复选框不可单独改；选「仅监听所选」时至少要勾一台。

「设备参数」那张卡只有一组值（型号、设备 DID、TTS 开关），代表默认设备，不会因为多选音箱变成多张。

## 登录与续期

| 方式 | 说明 |
|---|---|
| 扫码 | 最稳，日常首选 |
| 账号密码 + 验证码 | 只通过模拟测试，真实账号未验证；邮箱验证码只识别不发送 |
| 手动 Cookie | 真实账号实测可用；浏览器 F12 里取 `userId`、`passToken` |
| 浏览器代签 | Cookie 被拒（`70016`）时用，打开 `serviceLogin?sid=micoapi&_json=true` 复制整段返回 |

**遇到 `70016`**：多半是票失效了。在浏览器退出小米账号、重新登录，复制新的 `userId` /
`passToken` 再试；还不行用「浏览器代签」；再不行改用扫码。

插件会在令牌过期前自动续期（默认每 6 小时），只有小米明确拒绝凭据时才需要重新登录。
想改周期就改 `/data/config/config.yaml` 的 `xiaomi.token_refresh_hours`（15 分钟到 7 天），改完重启。

## 数据在哪

| 内容 | 位置 |
|---|---|
| 配置 | `/data/config/config.yaml` |
| 小米凭据 | `/data/config/auth.json`、`/data/config/.mi.token` |
| 直连令牌 | `/data/config/.access_token` |
| 日志 | `/data/logs/bridge.log` |

数据不上传给作者，但运行时会与小米服务端、你填写的 Home Assistant 通信；开启「AI托管」后，
未匹配的语音文本会发给你配置的 AI 接口（默认关闭）。`/data` 会随 HA 备份一起备份，
**备份里含凭据**，请自己保管。

## 常见问题速查

| 现象 | 先做什么 |
|---|---|
| 侧边栏没有面板 | 加载项在运行？打开「显示在侧边栏」？是 HA 管理员？ |
| 说话没反应 | 仪表盘「最近」有没有新语音：没有是登录态问题，有是规则问题 |
| 有语音但设备没动 | 规则页测试区验证匹配，核对实体 ID |
| 定时任务时间是错的 | 检查 HA 时区设置 |
| 直连端口要令牌 | 高级设置 →「显示直连令牌」 |
